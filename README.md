# cnc-material-workbench

備料工作台：厚 × 寬 × 長計算、每側加工留量與同材質規格比對。

單一檔案 `index.html`，用瀏覽器直接打開即可使用；也可以開 GitHub Pages（Settings → Pages → Branch: `main` / root）。資料只在瀏覽器裡處理，不會上傳。

## 功能

1. **備料計算**：輸入成品厚、寬、長與每側留量（預設每側 2 mm，各方向共 +4 mm），得出備料尺寸、毛重與件數合計。
2. **材料規格價格表**：三種方式擇一，載入的表會記在這個瀏覽器裡。
   - 直接從 Google 試算表載入：填網址與「分頁名稱 = gid」清單。試算表需設為「知道連結的任何人可檢視」，或各分頁「發佈到網路」成 CSV 後填網址。
   - 載入試算表下載的 `.xlsx`（讀全部分頁），或每分頁一個 `.csv`（檔名＝供應商）。
   - 從試算表複製整個分頁貼上。
3. **同材質規格比對**：
   - 只比對同牌號，不把 SS41／S45C／S50C 等互相替代。
   - 厚度須 ≥ 備料厚度；長寬有標才比對（可選擇允許旋轉 90°），沒標就列「長度待確認」。
   - 依「厚度多出量 → 面積」排序。
   - 單位是「元/kg」時才估材料費（供應商斷面 × 備料長 × 密度），空白價格不是 0 元。

規則與 `cnc-work-order` skill 的 `material_match.py` 一致；表頭關鍵字在 `index.html` 的 `COLS`，試算表表頭不同時在那裡調整。

## 注意

- 規格有列出不代表有貨，請向供應商確認庫存。
- 材料費為估算，未含鋸路損耗、最低計費重量、稅別、加工與運費。
- 留量是製程偏好，不是圖面公差；圓棒、鑄鍛件或異形毛胚請另行規劃。
